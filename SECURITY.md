# Security

Entries describe valid-but-awkward ledger data. Some of them can crash or corrupt software
that handles them badly. If an entry here reveals a vulnerability in a Stellar SDK, indexer,
or service that is not already public, **report it to that project's maintainers first** and
do not add it to the corpus until they have shipped a fix or agreed to disclosure.

To report a problem in this repository, use GitHub's private vulnerability reporting.
